# README images

The main README uses the existing app icon from `desktop/assets/AppIcon.png`.
Do not replace the icon or character artwork when updating these images.

| File | Source |
| --- | --- |

The demo links open the original videos on X. Keep the posters local so the
README can show them without a third-party image request. GitHub does not
run X's video embed script in a README.

When updating screenshots, serve the current HTML, CSS, JavaScript, and
character assets with sample API responses. Never capture private account
details, network addresses, project paths, or conversation history. Update
both appearances together. Keep the whole interface in frame and use JPEG
for the screenshots and SVG for the diagrams.

Theme selection follows [GitHub's picture markup](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/quickstart-for-writing-on-github#adding-an-image-to-suit-your-visitors).

authors. Character art keeps its existing rights; see
[third-party notices](../../THIRD_PARTY_NOTICES.md).
