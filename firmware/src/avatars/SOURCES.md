# Character sources

- **Muse:** the native Muse Gadget SDK animation. Maestro leaves its renderer intact.
- **Claude:** Clawd Tank by Marcio Granzotto Rodrigues, commit `a8942d140eeb8bcf549857ad599f7d62fd29eb01`, https://github.com/marciogranzotto/clawd-tank. The six sprite headers and RLE decoder are unchanged upstream files. MIT license: `Clawd-LICENSE.txt`. This is a community animation of Clawd, not a claim of Anthropic endorsement.
- **Codex:** the original OpenAI Codex companion, `codex-spritesheet-v6-51045ae208c0.webp`, from the user's installed Codex app. `scripts/build-codex-sprites.py` converts selected rows to RGB565 without redrawing them. The original file is in `bridge/public/characters/codex.webp`. This asset is not covered by Clawd's MIT license; this repository and app are private personal builds. Obtain redistribution permission before a public release that includes it.
- **Grok Bot:** Maestro's procedural animation of the round black character and white eyes in the user's reference. Its motion and AMOLED outline are Maestro adaptations, not an official xAI animation. Listening, thinking, speaking, error, sleep, and pet/completion poses use the existing SDK state. The expressive-eye approach is informed by Novra’s independent concept at https://www.novra.design/case-studies/grokbot; no Novra/Rive files are bundled.
- **Pi:** the official three-color mark from https://pi.dev/logo-auto.svg (retrieved 2026-10-09). The firmware reproduces its geometry and adds small movement. It is a logo, not an official character.
- **Dot:** mint diamond and sunglasses based on the owner's supplied reference. `bridge/public/characters/dot.png` is the source sprite generated with the built-in image-generation tool on 2026-10-10. `scripts/build-dot-sprite.py` encodes it as 48×48 RGB565 cells with eight colors. Listening, thinking, speaking, error and sleep use Maestro's own motion; this is not an official OpenAI animation.

Frame mapping: Codex idle (row 0), speaking/wave (3), thinking/run (7), error (5), listening/wait (6). Clawd uses idle, alert, thinking, happy, confused, and sleeping. The SDK's state selects the animation.

Added characters render on a 320×320 canvas. Codex's original poses are sampled on a fixed 48×52 grid; Clawd uses its original pixels at constant 2× scale. Grok, Pi and Dot use 4px cells, without blended edges. Dot's renderer separates its existing glasses into a moving layer, merges two mint shades, and adds eyes and a mouth for reactions. Picker portraits use the same artwork with nearest-neighbor sampling; Muse's portrait starts from its unshaded native cells. The native Muse animation stays intact. Hidden characters stop drawing while a list or reply reader covers them.

Dot generation mode: reference-image edit, transparent background. Exact prompt:

> Use case: style-transfer. Asset type: production pixel-art character sprite for a 466px retro handheld screen. Reference image is the user's Dot character identity, NOT a scene to reproduce. Create one clean front-facing sprite of this mint/teal rounded diamond wearing wide black wayfarer sunglasses. Preserve its simple squat diamond silhouette, soft truncated corners, glasses shape and cool expression. Authentic 32-bit-era pixel art drawn on a strict 48 by 48 logical pixel grid, enlarged with nearest-neighbor pixels. Very limited 6-color palette, square pixels, stepped outlines and small stepped cel highlights; no smooth or antialiased edges, no gradients, no texture, no dithering, no glow, no outline surrounding the canvas. No limbs, no extra character features, no props, no mouth, no text. Center one complete character inside a square canvas, use about 80 percent of canvas width and height, equal transparent margin all sides. Transparent background, no ground shadow. This must be a usable single sprite that still reads clearly at 48 pixels.

The generated source is preserved; the encoder reduces it to the device's eight-color palette and fixed grid.
