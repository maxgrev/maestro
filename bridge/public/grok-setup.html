Your Bot uses its existing Mac connection to return spoken replies to Maestro.

Create a routine

  1. Open Grok Bot and choose the Bot you want to use. Create a routine named Maestro voice remote.

  2. Use the instruction below. Allow the routine to use your existing Mac connection.

  3. Add a webhook trigger. Copy its URL and key into Maestro’s agent setup.

  4. Send “Hello” from Maestro’s Conversations page. A reply there confirms the full connection.

This needs Grok Bot’s webhook and Mac connection features. Provider sign-in and access prompts stay in Grok Bot.
