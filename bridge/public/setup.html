Connect over USB

Connect your StopWatch to this Mac with a USB data cable.

Connection tips

If the StopWatch doesn’t appear, try another cable or USB port. Some cables only support charging.

Firmware files are missing. For a source checkout, run npm run firmware:build, then refresh. If you downloaded the Mac app, reinstall it.

Install or update Maestro

Keep the cable connected. Maestro saves a recovery copy before installation and keeps your Wi-Fi and Muse pairing.

Wi-Fi tips
